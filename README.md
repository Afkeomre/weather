# 🔆 Приложение для отслеживания погоды

Это простое приложение для поиска погоды, которое позволяет пользователям вводить название города и получать текущие погодные условия для этого местоположения. Интерфейс реализован с использованием адаптивной верстки и включает в себя строку поиска, сообщения об ошибках при неправильном вводе и визуальное отображение данных о погоде.

## 🌐 Веб-сайт
Узнать, какая погода сегодня в Сиднее, Осло или любом другом городе, можно [здесь](https://afkeomre.github.io/weather/).

## ✔️  Особенности  

- **Функционал поиска**: приложение позволяет пользователям вводить название города для поиска текущих погодных условий.
- **Отображение погоды**: отображает текущую температуру, погодные условия, местоположение и дату.
- **Обработка ошибок**:  выводит сообщение об ошибке, если вводимые данные неверны или если местоположение не может быть найдено.
- **Динамические темы**: веб-сайт автоматически меняет фоновое изображение и цвет кнопок в зависимости от температуры. Существует две темы: "холодная" для низких температур и "теплая" для высоких.
- **Адаптивный дизайн**: интерфейс адаптируется к различным размерам экрана, обеспечивая удобство работы как на десктопах, так и на мобильных устройствах.

## 🛠 Используемые технологии
- **Vue.js**. Этот проект создан с использованием Vue.js, популярного фреймворка JavaScript для создания пользовательских интерфейсов. Vue.js известен своей простотой и гибкостью, что делает его отличным выбором для разработки адаптивных и интерактивных веб-приложений, таких как это приложение для поиска погоды.
- **OpenWeatherMap API**. Данные о погоде берутся из OpenWeatherMap API. Это надежный и простой в использовании API, который предоставляет информацию о погоде, такую как температура, влажность, скорость ветра и многое другое. Этот API доступен бесплатно (с ограничениями) и поддерживает поиск данных о погоде в городах по всему миру, что делает его идеальным для обновления погоды в реальном времени в этом приложении.
Чтобы узнать больше об OpenWeatherMap API, посетите [их официальный веб-сайт](https://openweathermap.org/).
